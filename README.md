Hi, this is a demo of an online museum project that I made for the Sun Yat Sen Museum here in Penang, Malaysia.
I made the use of THREE.js for the 3D render of objects that are actually in the museum.
I also made the use of an online Ai to model service called Aiuni. It converts images to a 3D model.
Some models like the iconic meeting table, I made it myself using blender.
